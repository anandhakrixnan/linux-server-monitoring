Run Locally

Clone the repository and start the monitoring services using Docker Compose. 

git clone git@github.com:anandhakrixnan/linux-server-monitoring.git
cd linux-server-monitoring
cp .env.example .env

# Configure the Grafana password in .env
nano .env

docker compose up -d
docker compose ps

Grafana: localhost:3000
Prometheus: localhost:9090
